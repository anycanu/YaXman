# YaXman取关查询

YaXman取关查询是一个 Chrome Manifest V3 扩展，用于在 X / Twitter 页面中监测已观察到的互关账号关系变化，并在发现对方取消关注时提醒。

## 功能

- 监听页面 DOM 和页面正常浏览产生的 GraphQL 返回数据
- 发现已记录互关账号不再关注你时，通过系统通知、插件栏徽章和页面内浮球提示提醒
- 保存历史取关记录
- 点击历史记录可打开对应 X 主页，方便手动处理关注关系
- 支持 `https://x.com/*` 和 `https://twitter.com/*`

## 准确性说明

为了降低对账号权重和平台风控的影响，扩展不会自动高频请求接口，也不会自动翻完整个关注列表。它的准确监测范围是“已经在页面中观察并记录过的互关账号”。对于几千或几万粉丝账号，建议在正常浏览关注/粉丝列表时逐步建立观察快照。

## 本地安装

1. 打开 `chrome://extensions`
2. 启用“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目文件夹
5. 打开或刷新 X / Twitter 页面
